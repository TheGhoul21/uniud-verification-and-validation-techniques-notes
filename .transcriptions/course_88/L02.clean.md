Last week we introduced the basic terminology and notation, and then we started with the first two classes of automata. This part is about the basics of automata theory. In particular, we introduced two classes of automata that we denote respectively by DFA and NFA, which stand for deterministic finite-state automata and non-deterministic finite-state automata.

They are tuples. The components are: a finite set of states, a finite alphabet, a transition relation — and there lies the difference between deterministic and non-deterministic automata — an initial state q0, which is a state in Q, and a subset of final states. These are the five components of our automata.

The difference between the two is in the transition function. In the case of DFA, the transition function delta goes from one state and one symbol of the alphabet to Q — given a state and the current symbol we are scanning in the input word, we determine the next state. In the case of NFA, the domain is the same, but the codomain is a set of states. The idea is that when I am in a given state and I read a given symbol, in general there are more than one state where I can go — and this is non-determinism.

To make it immediately clear whether we are dealing with DFA or NFA, we usually represent the NFA transition function as a relation. Instead of using lowercase delta, we use capital Delta, and we say it is a subset of Q times A times Q. This is essentially the same object, because if we define the transition function as a relation, it can be the case that for the same state and the same symbol, we have more possibilities for the target. So we use lowercase delta for DFA and capital Delta for NFA — this is just notation.

In the case of DFA, the acceptance condition is the obvious one. We start from the initial state, we scan the word, and we accept it only if we are able to complete our computation and end in a final state. There is at most one computation. If the automaton is complete — meaning for any state and any symbol, there is always an exit transition, I always know where to go — then there is exactly one computation. To be successful, we must end in a final state.

In the non-deterministic setting, there are more possibilities for defining the acceptance condition, and the one we use is the existential one. Starting from q0 and scanning a given word, we have more than one computation, and we say the word is recognized — it belongs to the language defined by the automaton — only if at least one of these computations ends in a final state.

We concluded last week by saying that from the point of view of expressive power — the languages we are able to define — the two classes of automata are equivalent. They define exactly the same class of languages. This was a theorem. One direction is trivial because a deterministic automaton is a special case of a non-deterministic one. The other direction is the difficult one: we have to show that whenever we have a language defined by an NFA, we are able to build an equivalent DFA.

This is what I'm going to show now. I will skip some details and leave them to you — you can find them in my notes on my web page under courses. They are in Italian, but I think anyone can read them. Otherwise, there are many textbooks about this. This is classical automata theory.

I want to give you the idea. This is something most of you probably already know, because it's a classical construction and a constructive proof. We show how to build a DFA, given an NFA, that recognizes exactly the same language. The construction is known as the power set construction.

Let us start with an NFA. Let A equal the tuple Q, A, Delta — where Delta goes from Q times A to the power set of Q — q0, and F. This is an NFA that accepts a language L.

The DFA that recognizes L is defined as follows. We call it A prime, and we name its components Q prime (the new set of states), the same alphabet A, Delta prime (the new transition function), q0 prime (the new initial state), and F prime (the new set of final states).

The key point is how we define these components. First, Q prime is the power set of Q. Here you see what we have to pay when going from a non-deterministic automaton to a corresponding DFA: there is an exponential blow-up in the number of states. The two have the same expressive power — they define the same set of languages — but in general, the DFA is more expensive because it may involve an exponential number of states with respect to the original NFA.

The alphabet is the same. The initial state q0 prime is exactly the singleton set containing just the initial state of the original automaton. Remember that the states of the new automaton are subsets of the set of states of the original one, so here we have the singleton with the original initial state.

Now we have to define the other two components. First, the transition relation. Delta prime is the transition function of the DFA — a deterministic transition function. It is defined as follows: for all P belonging to Q prime — so for all subsets of Q — and for all symbols a belonging to A, we define Delta prime on P and a as Delta applied to P and a.

Here, P appears in two roles. In the first position, P is an element of Q prime — a state of the new automaton. In the second position, P is a subset of Q. If you remember, last time we showed how to generalize delta from single states to sets of states. So Delta prime on state P and symbol a in the new DFA equals the result of applying the original Delta to the set of states P and the symbol a.

Finally, we have to specify how F prime is defined — the set of final states of our new deterministic automaton. Remember that the acceptance condition of the original non-deterministic automaton is existential: we say the automaton is successful on a given input word if at least one computation ends in a final state.

How do we transfer this condition to the new automaton? We say that a state P belonging to Q prime is a final state if, when we look at the states inside P and intersect with the original set of final states F, the intersection is not empty. So we collect all states of the new automaton such that at least one of the component states from the original automaton is a final state. If a computation ends in such a state, we recognize the word.

This is the definition. You need to prove that it actually works. The basic step of the proof is the following — I invite you to do it by yourself, and if you have any problem, let me know next lecture.

We can prove by induction on the length of the input word W that Delta prime, starting from q0 prime on the input word W, equals the set of states reachable in the original automaton starting from q0 on W. Here you have a set of states on one side and a single state on the other — but that single state is essentially a set of states of the original automaton. You have to prove they are the same set.

If you prove that, you are essentially done, because you can exploit this equality to show that the computation of the original automaton is successful — meaning it reaches at least one final state — if and only if the computation of the new automaton reaches a state whose intersection with F is non-empty, which is final by definition. And vice versa.

I leave the completion of this proof to you — there are no surprises. It's an easy proof.

Note that thanks to this result, we can redefine the notion of regular languages. Remember, a language is a subset of A star — the set of all finite words over the alphabet A. A language is regular if and only if it is recognizable by a DFA. Thanks to the equivalence between DFA and NFA, we can also say that a language is regular if and only if it is recognizable by an NFA. The two classes are equivalent. We can use one class or the other depending on our convenience, and we will exploit this opportunity by choosing the most suitable class depending on what we want to do.

The main difference between the two classes is the complexity of the automaton. In general, deterministic automata are bigger than non-deterministic ones for the same language, because in principle there is this exponential blow-up from Q to the power set of Q. This is not always the case — maybe some of the constructed states are not reachable and are useless. In lucky cases, we can keep the DFA linear or polynomial in the size of the original automaton. But in some cases, the exponential blow-up is real.

Now I'm going to introduce another class of automata — the last one, and I think you have already met it somewhere. This is a variant of the NFA: the class of NFA with epsilon moves.

The idea is that these are non-deterministic automata with one more capability. When I'm in a state, I can also move without consuming any symbol. Up to now, we always needed to consume one symbol to move from one state to another. In these automata, you still have that possibility, but you also have the possibility at any step of moving without consuming any symbol — an epsilon move. Since the automata are non-deterministic, in general when I'm in a state and I make an epsilon move, I can go to multiple other states.

This gives much more flexibility. You are not constrained to always consume a symbol to move. While this is interesting, it is a powerful form of abstraction. You can say: I don't care about the details, I don't want to keep track — I just want to record that I can move. I consume nothing at this level and I proceed. That's the intuition.

An NFA with epsilon moves is a tuple: Q, A, Delta, q0, F, where Q, A, q0, and F are defined as usual. Delta is defined as follows: it starts from a state, and the second argument is the set of symbols union epsilon — the empty word. The codomain is the power set of Q. If you remove the epsilon, this is exactly as in the case of NFA. By adding epsilon, you add the possibility of making a move starting from a given state Q and reading nothing.

Let Q be a state, an element of capital Q, and let P be a subset of Q. An epsilon move is a transition of the form Delta(Q, epsilon). You are in state Q, and you can go to other states by consuming nothing.

When you are in Q, you can go to some states by an epsilon move. But then from each of those states, you can either consume a symbol or apply another epsilon move. And from those states, more epsilon moves, and so on. So it makes sense to ask: starting from Q, where can I go without consuming any symbol, by iterating epsilon moves as long as possible?

I don't just want the immediate successors reachable by one epsilon move — I want all states reachable by only applying epsilon moves starting from Q. Since we are talking about finite-state automata, this process terminates — the total number of states is finite, so in the worst case you reach all states. By a simple fixed-point computation, you go on until you cannot add any new state, then you stop.

This set of states is called the epsilon closure of Q. The epsilon closure of a given state is the set of states reachable from that state by applying an arbitrary number of epsilon moves. This process terminates because the total set of states is finite.

Why is this important? Because the notion of epsilon closure is needed to define the computation of an NFA with epsilon moves over a given word. You are in the initial state, you receive the input word, and you proceed as follows: you apply the epsilon closure to collect all reachable states, then you consume the first symbol, then you apply the epsilon closure again, then you consume the next symbol, then epsilon closure again, and so on until you've consumed the entire word and applied a final epsilon closure.

The acceptance condition is the same as for NFA: we accept the word if at least one of the states reached in this way is a final state.

Let me formalize this quickly. First, I generalize the epsilon closure from a single state to a set of states. For all P belonging to the power set of Q, the epsilon closure of P equals the union of the epsilon closures of each state p in P. This is straightforward.

Now I can define hat-delta. Hat-delta of Q and epsilon — where I'm in state Q and I read the empty word — equals the epsilon closure of Q. This is the base case. If I am in Q and I can only read epsilon, I apply epsilon moves until I reach all reachable states.

The inductive step: for all words W and symbols a, hat-delta of Q applied to Wa equals the epsilon closure of the union, for all states P belonging to hat-delta(Q, W), of Delta(P, a).

Let us read this definition together. The set of states reachable starting from Q by reading Wa is computed as follows: I compute the set of states reachable from Q by reading W. For each of these states P, I apply the transition that consumes a. Then for each state reached in this way, I apply the epsilon closure. If you put together the base case and the inductive step, you get exactly what I described: epsilon closure, consume a symbol, epsilon closure, consume a symbol, and so on, until you've consumed the last symbol and applied a final epsilon closure.

One remark: epsilon moves are something which is no longer interesting when we move to automata that work on infinite words. In the finite setting, epsilon is a finite word — the empty word. In the infinite setting, epsilon is no longer a word of your universe, and epsilon moves are no longer meaningful. So this is very interesting in the finite setting we are considering now, but not in the infinite setting.

Now for the definitions and the main theorem. A finite word W is accepted by an NFA with epsilon moves, calligraphic A, if and only if hat-delta starting from q0 on W, intersected with F, is different from the empty set. This is exactly the same definition as for NFA: I accept if at least one of the states reached through the alternation of epsilon closures and transitions is a final state.

The language accepted by the automaton, L(A), consists of all and only those words over A accepted by calligraphic A. This is again standard.

Now there is a theorem that tells us the relationship between NFA without epsilon moves and NFA with epsilon moves. The question is: do we increase the expressive power by adding epsilon moves? The theorem says the following: for all NFA with epsilon moves, calligraphic A, there exists an NFA without epsilon moves, A prime, such that the language recognized by A equals the language recognized by A prime. And trivially, vice versa.

The point is that everything I can do with epsilon moves, I can do without them. This addition does nothing to increase expressive power. It is a useful feature — a way of abstracting from details — but there is no improvement in expressiveness.

I just want to give you the idea of the proof. Keep in mind that with these two theorems, we are saying that what I can do with DFA is exactly the same as what I can do with NFA, which is exactly the same as what I can do with NFA with epsilon moves. These three classes of automata define exactly the same languages. No gain in terms of power — in terms of convenience, yes, but not in terms of expressive power.

One direction is trivial: an automaton without epsilon moves is a special case of one with epsilon moves. The interesting direction is how to remove the epsilon moves.

Let calligraphic A be the tuple Q, A, Delta, q0, F — an NFA with epsilon moves that accepts language L. An equivalent NFA A prime without epsilon moves is defined as follows: A prime has the same set of states Q, the same alphabet A, a new transition function Delta prime, the same initial state q0, and a new set of final states F prime.

Delta prime on a state Q and a symbol a equals hat-delta(Q, a) in the setting of automata with epsilon moves. This means: I'm in Q, I apply the epsilon closure, I reach a set of states. Then I consume a from each of those states. Then I apply the epsilon closure again. Written explicitly, this equals the epsilon closure of the union, for all P belonging to the epsilon closure of Q, of Delta(P, a). So I collect all the states reachable in the original automaton starting from Q through one step of epsilon closure, consumption of a, epsilon closure — and I say these are the states reachable in one step by consuming a in the new automaton.

To complete the proof, I need to define the set of final states. F prime equals F, the original set of final states, with one special case: I have to take care of the case where, starting from the initial state and applying only epsilon moves, I can reach a final state. I handle this by adding q0 to F prime if the epsilon closure of q0 intersected with F is non-empty. If I can reach a final state from q0 by only applying epsilon moves, I add q0 to F prime. Otherwise, F prime equals F.

Now, with a bit of time remaining, I want to take a couple of steps into a new chapter that I already mentioned: regular expressions. I'm going to use regular expressions as an alternative way of defining languages, instead of using automata.

There are three classes, and I start with the class of restricted regular expressions. They are built from a finite set of words over the alphabet A — but for simplicity, you may think of a finite set of symbols, since single symbols are just words of length one. We build these expressions using three operations.

The first is union. If you have symbol A and symbol B — singletons — you make the union and get a new set that includes both A and B. The second is concatenation. I can build new words by juxtaposing two words: AB concatenated with BC. We already saw how to generalize concatenation from single words to sets of words — the concatenation of two sets is the set of words obtained by taking one word from the first set and concatenating it with one word from the second. The third is the Kleene star, also called Kleene closure.

To make it clear: consider the singleton A concatenated with B star. B star is the set of all finite words built by concatenating zero, one, two, three, or more occurrences of B — the empty word, B, BB, BBB, and so on. The concatenation produces the language: A, AB, ABB, ABBB, and so on. This is the infinite language defined by this restricted regular expression.

Using union, I can write something like A concatenated with B star, union B concatenated with A star. This gives us the language of words that start either with A or with B, followed by an arbitrary number of the other symbol.

So we use concatenation, union, and the Kleene star as operations to define a language, starting from basic words.

The second class is given by general regular expressions. These are defined as restricted ones — starting from a finite set of symbols, using union, concatenation, and Kleene star — plus two additional operations: intersection and complementation. Intersection is the intersection of languages. For example, if instead of making the union of two languages you make the intersection, the resulting language contains only words belonging to both. Complementation, in set-theoretical terms, means taking the complement of a set with respect to the universe A star. So the complement of a language is the set of all words over the alphabet that do not belong to that language.

Each language definable with restricted regular expressions is also definable with general regular expressions — trivially, since general expressions have a superset of the operations.

The third class is called star-free regular expressions. These are defined as general regular expressions, but without the Kleene star. So we take the operations of general regular expressions and forbid the use of the star.

Now the question: what is the relationship between these three classes in terms of expressive power? We already know that general regular expressions are at least as expressive as restricted ones, and also at least as expressive as star-free ones.

The first result is surprising: restricted regular expressions are exactly as expressive as general regular expressions. I do not lose anything by removing intersection and complementation. This is not a trivial result — the proof exploits automata, and we will see how.

On the contrary, if we remove the Kleene star, we lose expressive power. Star-free regular expressions are strictly less expressive than general (and thus also restricted) regular expressions. Removing complementation and intersection does not decrease expressive power, while removing the Kleene star does — which means the Kleene star is truly powerful. If you think about it, the Kleene star allows you to generate infinite sets from finite ones in a very strong way.

We will explore this further. At the beginning, we mainly focus on restricted and general expressions and show the equivalence between the two. We will say something about star-free expressions later in this course, maybe in the second semester. But keep in mind this picture.

To show the equivalence between restricted and general, we make use of automata. To show the result about star-free expressions, we make use of logic. Because in the end, automata, regular expressions, and logics are different tools for doing the same thing: defining languages. That's the point.
